# Source attribution

Third-party repository licenses and attribution remain in their source trees.
The `crates` directory and local `vendor/field` implementation retain their
existing license notices. BitZ includes reused Zinc+ implementation code as
documented in its source comments; the external Zinc+ comparison is omitted.

Limber derives from Spartan2 and retains its upstream license and references.
This ancestry does not introduce an external Spartan2 comparison dependency.
Upstream bibliographic attribution is retained even where a cited author also
contributed to the benchmark forks. Commit metadata normalization is described
in the provenance manifest; it does not replace third-party license notices.
